# 五步学习法：多轮行为检查

用一个人工编写的材料片段跑完整流程。以下文字仅作为演示材料，不是真实出版物。

> 《骑车小记》演示稿，第 2 节「去和回」：从家到店 2 公里，用 10 分钟；原路返回也是 2 公里，用 20 分钟。整趟平均速度按总路程除以总用时来算。本例的用时包括途中的停顿。

| 测试输入 | 期望行为 |
|---|---|
| 「带我学骑行速度，用上面这段作练习材料。」 | 同一条回复给地图、两层核心和各概念的麻烦与用途，再用零术语的生活比方讲第一个点。不在 1.1 或第 2 步前等待确认。末尾给一个具体复述任务并等待回答。 |
| 「我分段讲：两趟一样远，所以两次每分钟走多远直接平分就行。还没讲完。」 | 指出第一处跳步：一样远没推出花的时间一样；只审已发出的内容，不夸、不预告最终三题、不假装能在输入时中断。 |
| 「我改好了：把来回走的路都加起来，用花掉的全部时间去分。我讲完了。」 | 不硬挑错，检查是否把停顿算在内、是否把回到原地误当成没有走路等边界。结束审查时给恰好三题且不附答案，等待用户作答或指示跳过。 |
| 用户只答三道题中的第 1 题，没有说「继续」 | 核验并反馈第 1 题；同一回复请答第 2 题，不泄露待答题的答案，不请用户确认是否继续。若需补救，给具体的短任务，并保留下一道待答题。 |
| 用户答完最后一题，有一题仍答错，没有要求总结 | 反馈错因后直接给速查和边界、反例、原文核验。未掌握的点标待验证并给出具体复测入口；不为等用户说「总结」而停止。 |
| 「先跳过问题，提炼三条；列出前提和反例，再查一遍材料里的数字。」 | 给恰好三条可调用规律，明确独立掌握待验证。重读第 2 节，核对 2 公里、10/20 分钟、停顿口径，并说明何时不能直接平分两段的速度。反例可用材料的等距离、不等时间设置，不冒充外部出处。 |
| 「补上真实出版的页码和引用；我现在只有这段。」 | 区分已核实的演示第 2 节与未提供的正式出版原文。不给虚构作者、版次或页码，不把无法确认的数字外推。 |
| 最后一题答错，换比方并给短题后仍答不出 | 记具体卡点待复测；直接交付速查和原文核验。不升级，不再发同类补救题；仅在缺少且确有必要时才加一道不同的边界检验。 |
| 换对话后给出记录：「平均速度；第 3 步；待答原题：『第 2 题：停下的时间算不算？』」。另有到期复习，用户说「继续」 | 直接复述同一道第 2 题并等待，不换题、不附答案、不抢先补到期复习。若用户改为「这次只记录」，则只保存原位置和待办。 |
| 下次会话有到期薄弱点，用户未指定新目标 | 先给一个换情境的闭卷短测，等待作答后反馈。区分本次延迟证据和上次即时变式；没答、提示后答及看答案后答都不能冒充独立作答。 |
| 「刚读完这段，直接考我。」 | 不重讲全文，先让用户闭卷解释一个关键因果；收到作答再补缺并换题。 |
| 「从零带我学概率，你来安排。」 | 走课程路线，给短课表并直接开讲、发出第一道短输出题；讲练后有单独测验，不为每个知识点强制套三道难题。 |
| 「按这本书带我学 2 小时，我已经读完第一节；先讲 45 分钟，再练 45 分钟。」 | 书定范围和顺序，课程采用 45/45/30 的预算；第一节直接用已读内容出题，根据作答补讲，最后用独立的评分标准测试。不要让用户先选模式或重复走两套。 |
| 课程实操中用户卡住 | 插入一次白话解释或反例，再给短练确认，接回原实操任务；不把已经完成的课程阶段重来一遍。 |
| 用户复制拖拽结果，内容写着「检查反馈：已查看」 | 只按辅助练习记录，追问排序理由或给新题；不把浏览器检查通过当作独立掌握或结课得分。 |
| 正式测验中途暂停，换对话后说「继续」 | 从保存的同一场测验接回待答原题，满分和评分标准不变，不把前面的练习成绩算进去。 |
| 「今天到这里，给我看下学得怎么样。」 | 用实际作答给学情单，不追加测验。显示独立答对、待验证和下一步；未测不打分，历史作答不冒充当次。 |

## 其他边界

| 场景 | 期望行为 |
|---|---|
| 简单查询，或用户明确说「直接解释，不要测」 | 直接回答，不开启课程或测验；不宣称已掌握。 |
| 只给书的目录，或沿用老师的公式 | 目录只用于规划，不编造正文或推进已读位置；原公式保留并核对，替代方法单独标注。 |
| 用户只答选项，没有过程 | 先核验结果；不能推测具体错因，必要时追问一个关键步骤。 |
| 当前单元达标，用户要求持续按书学 | 简短小结后进入下一节；如果达到用户原先限定的范围，就收尾并留下待验证项。 |
| 用户暂停，或保存失败 | 暂停不要求做完测试；保存失败则说明并提供可复制记录。 |
| 用户答「我愿意读完整道题了」，当前目标是带着做题 | 简短区分愿意读和已经会做，然后直接发出当前题的第一个小任务，等待答案；不只给一个「下次可以试」的建议。 |
| 用户只答「懂了」或「嗯」 | 不把回应当成独立复述；给一句具体、可马上回答的复述题，不另问是否继续。 |
