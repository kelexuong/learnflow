# 五步学习法：多轮行为检查

用一个人工编写的材料片段跑完整流程。以下文字仅作为演示材料，不是真实出版物。

> 《骑车小记》演示稿，第 2 节「去和回」：从家到店 2 公里，用 10 分钟；原路返回也是 2 公里，用 20 分钟。整趟平均速度按总路程除以总用时来算。本例的用时包括途中的停顿。

| 测试输入 | 期望行为 |
|---|---|
| 「带我学骑行速度，用上面这段作练习材料。」 | 普通学习请求直接进入五步，无需说「零基础速通」。给主题地图和两层核心，每个核心点有麻烦与用途；说明材料只覆盖所给范围。用常见事物打比方讲一个点，解释正文不出现学科术语；邀请复述后停下。 |
| 「我分段讲：两趟一样远，所以两次每分钟走多远直接平分就行。还没讲完。」 | 指出第一处跳步：一样远没推出花的时间一样；只审已发出的内容，不夸、不预告最终三题、不假装能在输入时中断。 |
| 「我改好了：把来回走的路都加起来，用花掉的全部时间去分。我讲完了。」 | 不硬挑错，检查是否把停顿算在内、是否把回到原地误当成没有走路等边界。结束审查时给恰好三题且不附答案，等待用户作答或指示跳过。 |
| 「先跳过问题，提炼三条；列出前提和反例，再查一遍材料里的数字。」 | 给恰好三条可调用规律，明确独立掌握待验证。重读第 2 节，核对 2 公里、10/20 分钟、停顿口径，并说明何时不能直接平分两段的速度。反例可用材料的等距离、不等时间设置，不冒充外部出处。 |
| 「补上真实出版的页码和引用；我现在只有这段。」 | 区分已核实的演示第 2 节与未提供的正式出版原文。不给虚构作者、版次或页码，不把无法确认的数字外推。 |
| 连续两次在等路程和等用时之间混淆 | 换解释或补缺，再出一道不同题验证；两次错误不等于要重复刷同一题。未作答的三道题只记待办。 |
| 用户给出已有记录：「三题中第一题已独立作答，下一步答第二题。」并要求继续 | 从第二题开始，不重画地图，不把第一题重新计作新证据。若用户改为「这次只记录」，则只保存原位置和待办。 |
| 下次会话有到期薄弱点，用户未指定新目标 | 先给一个换情境的闭卷短测，等待作答后反馈。区分本次延迟证据和上次即时变式；没答、提示后答及看答案后答都不能冒充独立作答。 |

## 其他边界

| 场景 | 期望行为 |
|---|---|
| 简单查询，或用户明确说「直接解释，不要测」 | 直接回答，不开启课程或测验；不宣称已掌握。 |
| 只给书的目录，或沿用老师的公式 | 目录只用于规划，不编造正文或推进已读位置；原公式保留并核对，替代方法单独标注。 |
| 用户只答选项，没有过程 | 先核验结果；不能推测具体错因，必要时追问一个关键步骤。 |
| 当前单元达标，用户要求持续按书学 | 简短小结后进入下一节；如果达到用户原先限定的范围，就收尾并留下待验证项。 |
| 用户暂停，或保存失败 | 暂停不要求做完测试；保存失败则说明并提供可复制记录。 |
