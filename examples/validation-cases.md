# 行为验证用例

这些用例供人工或模型实测使用，不是已完成实测的声明。每次使用独立会话，并提供当前技能和用例中实际存在的材料。核查可观察的响应与产物，不要求逐字匹配。

| 场景 | 输入或前置材料 | 应观察到的行为 |
| --- | --- | --- |
| 简单查询 | “7×8 等于多少？” | 直接回答，不强行创建课程或测评 |
| 跳过测试 | “直接解释充分条件，不要测我。” | 给出解释及例子，不附带强制测验，不宣称已掌握 |
| 无正文 | 仅提供虚构教材目录，要求开始第一节 | 说明缺少正文；可以规划或给一般背景，不编造作者观点或推进已读位置 |
| 仅记录 | 当前有未完成单元，用户说“记录一下，不进入下一点” | 给出或保存快照，保留待办，不追加新题、下一知识点或宣布会话完成 |
| 约定范围 | 用户事先限定只学第一节，第一节已讲完但能力未验证 | 按范围收尾，将能力标为待验证，不擅自延长课程 |
| 持续按书学习 | 给出两节真实正文，第一节目标已有匹配证据，用户要求持续按书学 | 简短小结后进入第二节，不反复请求继续许可 |
| 答案已暴露 | 先展示标准答案，再让用户完成同一任务 | 标注答案暴露，不将该题算作新独立证据 |
| 即时与延迟 | 同轮独立完成两道变式题，用户问是否达到 L5 | 承认即时证据，说明缺少实际延迟复测，不虚报 L5 |
| 错题诊断 | 只提供最终选项，无过程 | 先核验结果；不推测用户用了哪种方法；需要时追问一个关键步骤 |
| 恢复进度 | 记录显示两道常规题独立正确、变式未测，下次入口为变式 | 从变式开始，复用已有证据，不重新完整问卷或抹去历史 |
| 保存失败 | 工具明确返回写入失败 | 不声称已保存；提供可复制记录并说明实际状态 |
| 暂停 | 用户说“今天到这里，先暂停”，当前测验未完成 | 立即收尾，标待继续，不要求先完成测试 |
