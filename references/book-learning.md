# 按书籍与课程顺序学习

## 材料接入
1. 使用实际提供的文件或可访问资料，识别书名、作者、版本、目录、正文可读范围。目录与正文标题不一致时核对，不自行编造章节。
2. 若用户已指定起点，沿该位置开始；没有起点且没有有效历史，则从正文第一节开始。只问确实影响定位的一个问题。
3. 建立“章→节→知识点”路线，保留原书章节标题与顺序。教学拆分标签标为“教学单元”，不冒充原书小标题。
4. 长书分段读取，先目录和当前章节，不声称一次读完全部。只有目录时可规划；缺正文时请求当前小节，也可明确提供一般背景讲解，但不推进原书已读位置。
5. 扫描件/OCR不清时核对关键文字、公式；无法辨识的部分标待补充。不得用猜测填补来源。

## 推进原则
默认以原书顺序为主线，按掌握情况改变步长，不随意重排章节。每小单元：定位→原文核心论点/概念→必要解释与边界→学习者输出→反馈→更新进度。用户请求直接讲解时照做，并将独立应用标待验证。
原书内容、AI补充、生活举例分别标识；用户举例不是证明作者结论的研究证据。不完整复刻长篇受版权保护正文。
先修缺口触发临时补讲，记录返回锚点；补讲结束回到主线。已获持续按书学习的指令时，单元目标达成后顺序推进，不每次重复确认。用户指定范围、暂停、仅记录优先。
穿插复习时注明是复习任务，不改变主线阅读位置。用户跳节时记录“主动跳过”，不可标为读完或掌握。

## 两条进度线
- 材料进度：未读 / 进行中 / 已读 / 跳过；记录最后实际读取并讲解的位置。
- 能力进度：逐知识点记录等级、证据ID与待验证项；已读一章不等于该章全部掌握。
章节完成情况要同时显示“阅读完成”与“能力验证尚缺什么”，不以一个百分比混合两者。

## 定位与恢复
记录材料ID/文件名、版本、章节标题、小节、PDF文件页码（从1计）与书内印刷页码（如可见）、段落锚点、当前教学单元、下一起点、补讲返回点、复习待办。不能确认的页码留空并注明，使用标题/短段落锚点；不推算未知的页码偏移。
换版或重新上传时先比对目录与锚点，再映射位置；不要沿用旧页码。多个材料并行时分开进度，不混用。
续学先读取记录与当前正文：有未完成单元则继续；正在补讲则先补完返回；单元完成则进入已约定的下一节。记录冲突优先核实，不凭空创建过去的学习证据。
