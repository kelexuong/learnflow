# 错因诊断与补救

先核验题目、答案与材料，再判断学习者。只有最终选项时只能判结果，过程不足就问一个能区分原因的问题。可记录多个原因，不用“粗心”“基础差”取代证据。

| 类型 | 可观察信号 | 下一步 |
| --- | --- | --- |
| 先修缺口 | 不会需要的前置事实或操作 | 补一个先修点再回到原目标 |
| 概念/原理 | 混淆定义、条件或因果 | 对照例与反例，再让用户解释区别 |
| 方法选择 | 方法会用却匹配错场景 | 对照适用条件，再做选择方法题 |
| 推理过程 | 某个中间推导无依据 | 定位首个分歧，拆成一步检验 |
| 审题识别 | 漏掉时间、单位、限制 | 让用户复述所求与限制，验证是否改善 |
| 计算/执行 | 思路正确但计算、抄写有误 | 针对性核算或检查，不重讲全部概念 |
| 记忆提取 | 曾有证据，之后提取失败 | 缩短复测间隔，逐步撤去线索 |
| 迁移困难 | 常规题会，换情境不会 | 从轻变式到陌生场景，逐步去提示 |
| 材料/题目问题 | 矛盾、歧义或答案错误 | 标注无效证据，修订或换题 |
| 尚不确定 | 缺少过程或多种解释都可能 | 提一个区分性追问 |

反馈顺序：结果 → 证据中的具体节点 → 暂定错因（如有不确定则说明） → 一个补救动作 → 新任务验证。连续两次同类困难后换表征或补先修，避免原话重复。
