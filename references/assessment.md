# 能力阶梯与判定协议

等级按知识点记录；这是教学用规则，不是经校准的心理测量量表。

| 等级 | 原手册定义 | 需要的表现证据 |
| --- | --- | --- |
| L0 | 未接触 | 用户明确表示尚未接触；没有记录只标未评估 |
| L1 | 能识别 | 能辨认概念、给出基本定义 |
| L2 | 能理解 | 能解释为什么、条件或反例；提示下完成可作为辅助证据 |
| L3 | 能应用 | 多个有代表性的常规任务无提示完成 |
| L4 | 能迁移 | 不同表述或新场景中独立完成并说明迁移依据 |
| L5 | 能熟练 | 多次独立、稳定、高质量完成，含延迟复测；速度相关任务还须限时表现 |
| L6 | 能融会贯通 | 综合任务中比较方法、识别边界并创造性应用，或能教学并处理反例与追问 |

每条证据记：任务ID、日期、原始作答、结果、独立性、提示/答案是否暴露、是否迁移、是否延迟、用时（实际测量才填）。置信度可选，不替代能力证据。

判定步骤：
1. 核验题目与标准答案；有歧义或错误时作废该项测评，不归咎学习者。
2. 标记独立完成、提示后完成、看答案后完成或未完成。重复原题不视为新证据。
3. 将表现对应到能力维度。证据不足标“待验证”；有足够匹配证据才标“已验证”，并列出证据ID。默认用至少两个不同任务作为初步交叉验证，这是实践门槛而非普适定律；任务复杂性可调整，但要说明。
4. 分开记录“当前已验证等级”与“下一等级待验证表现”。尚未验证基础但出现高阶表现时，记录表现并用短题检查必要先修，不机械刷完所有级别。
5. 同一知识点即时正确不能证明延迟保持。L5 必须包含跨会话或有实际时间间隔的复测，不能把同轮换题称作延迟复测。
6. 一次失误先诊断，不自动降级；若多次独立证据显示能力不再稳定，保留历史等级与日期，更新当前状态并安排复测。

阅读、创作等不以速度为目标时，使用任务相关的质量标准；没有必要的限时证据标“不适用”，说明理由。教学表达是L6的一类证据，但只讲得流畅不等于融会贯通。
