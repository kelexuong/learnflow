# AI 课程带学：讲 → 练 → 测 → 评

当用户让 AI 安排整堂课时使用，也可作为按书学习的时间和产出框架。已经读过的部分不必再讲一遍；可用 [按书五步](five-step-learning.md) 的复述、错因诊断或边界检验决定需要补什么。

1. **排课并开讲。** 把目标缩到这次能完成的范围，给出讲、练、测的计划，再直接讲第一个核心概念。用户给 N、M、X 时，按 N 总时长、M 讲解、X 实操、N−M−X 测验排课；有矛盾只问一个关键问题。只给 N 时用 50/30/20 作可调整的默认预算；没给时长则先带一个短单元。未实际计时不声称已经用掉几分钟。讲解包含机制、典型应用和实战案例；从简单例子入手，核对需要更新的一手资料。每讲一个关键点就给一个短输出，避免讲完才发现没听懂。
2. **动手练。** 把关键判断变成可观察的任务。适合排序时生成 [拖拽排序页](learning-outputs.md#离线交互页)，请用户用「复制本次作答」交回实际排序，再补理由。复制文本标明是否看过检查；看过后重试记为辅助练习。没收到就不记完成。其他内容用模拟、判断、代码等可执行任务；错了就换讲法。无法生成页面时改用文字练习并如实说明。
3. **结课测。** 用选择、填空、情境问答等题型按目标测量。发题前用 [测验记录](source-library.md#课程断点与正式测验) 保存本场题目、满分和评分依据；至少一题要求理由或新情境应用。只向用户发题和必要规则，暂不展示答案要点。按本场首份独立作答评分，日常练习和看过反馈的重试另记，未完成不填零。需要改分保留原因；不套五步法的固定三题。无法保存时在当前对话先写明题分和评分口径，结果只作本对话反馈。
4. **可视化反馈。** 生成 [学情单](learning-outputs.md#可视化学情反馈)：显示各板块及总分、独立作答证据、实际卡点和具体下一题。未完成标部分测评；L0–L6 与百分制分开。用户暂停时按已完成范围反馈，保存剩余任务、待答原题和需要返回的阶段。

讲练测是安排整堂课的顺序，不是必须硬切的隔间。可以短讲后立即短练，再继续讲；根据实际作答缩短已经会的部分、把时间给卡点，仍保留约定范围内的代表性结课测验。短测用于调整教学，结课测验依据发题时的评分规则，不重复计同一份作答。

一次回复做完可连续完成的动作；发出明确任务后才等作答。输出后先给反馈，再接上下一步。保留用户可跳过、暂停、直接看答案和只记录的选择，不把这些行为算成独立作答。课程的隔时复测沿用 [复习规则](review.md)。
